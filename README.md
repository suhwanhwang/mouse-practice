# 🐭 마우스 섬 모험

아이패드 터치에만 익숙한 초등학생이 **마우스 사용법**을 게임처럼 배우는 웹사이트입니다.
섬 8개를 차례로 깨면서 이동 → 가리키기 → 클릭 → 더블클릭 → 오른쪽 클릭 → 끌어서 놓기 → 스크롤을 익히고, 마지막 섬에서 가짜 컴퓨터 화면으로 모두 합쳐 연습합니다.

| 섬 | 배우는 것 | 놀이 |
|---|---|---|
| 1 마우스 친구 만나기 | 잡는 법, 움직이기 | 별 꼬리, 반딧불 모으기, 나비 따라가기 |
| 2 비눗방울 공원 | 가리키기 | 비눗방울에 화살표를 올려 터뜨리기 |
| 3 풍선 축제 | 클릭 | 풍선 터뜨리기, 두더지 잡기 |
| 4 병아리 농장 | 더블클릭 | 알을 톡톡 눌러 병아리 부화 |
| 5 선물 가게 | 오른쪽 클릭 | 메뉴에서 열기·색칠하기·리본 달기 |
| 6 동물 마을 | 끌어서 놓기 | 동물 집 찾기, 과일 바구니, 퍼즐 |
| 7 바닷속 탐험 | 스크롤 | 바닷속 친구·보물 찾기 |
| 8 보물 컴퓨터 | 모두 함께 | 폴더 열기, 휴지통 비우기, 보물 상자 열기 |

- 모든 안내를 한국어 음성으로 읽어 줍니다(🐭나 🔊를 누르면 다시 듣기).
- 틀려도 벌점 없이 힌트만 나오고, 별 1~3개와 섬마다 스티커를 받습니다.
- 진행 상황은 브라우저(localStorage)에 저장됩니다.
- **부모 설정**: 지도 화면 왼쪽 위 `🏝️ 마우스 섬`을 3초 동안 누르고 있으면 열립니다. 음성, 효과음, 한 단계 길이(1·3·5판), 더블클릭 인식 간격, 휴식 알림, 모든 섬 열기, 기록 지우기.
- 한 단계는 여러 판으로 이어지고, 클릭·더블클릭·끌기 섬은 2판을 더 합니다.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173/mouse-practice/
npm test         # 단위 테스트 (vitest)
npm run build    # dist/ 에 정적 파일 생성
```

Vite + TypeScript, 프레임워크 없음. 그래픽은 이모지와 CSS, 효과음은 Web Audio로 합성해서 외부 에셋이 없습니다.

- `src/core/` 공통 기능 (저장, 소리, 음성, 드래그·더블클릭 판정, 효과)
- `src/ui/` 화면 (시작, 지도, 놀이 틀, 결과, 스티커, 그림판, 부모 설정)
- `src/games/` 섬별 게임. 각 게임은 `Game` 함수 하나(`src/core/scene.ts`)로, 결과·저장·힌트는 놀이 틀이 처리합니다.
- `src/data/stages.ts` 섬·단계 이름, 안내 문구, 스티커
